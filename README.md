
# Network Science and Data Analysis

This repository contains computational assignments I completed during my MSc in Mathematical Sciences at the African Institute for Mathematical Sciences (AIMS), Ghana, as part of the course *Network Science for Big Data*.

The assignments gave me practical experience using Python and NetworkX to construct, analyse and visualise networks, and to examine how individuals and groups are connected in real-world social networks.

## Assignment 1: Facebook Social Network

Using a Facebook social network dataset, I explored the structure of the network and examined how connections were distributed among its users.

The analysis included:

- Network construction and visualisation using NetworkX.
- Degree distributions and average degree.
- Degree, betweenness, closeness and eigenvector centrality.
- Clustering coefficients and triangle counts.
- Average shortest path length.
- Relationships between node degree and clustering.

[View Assignment 1](owusu_NSBD_Assignment_1.ipynb)

## Assignment 2: Dolphin Social Network

Using a dolphin social network dataset, I explored how individuals were connected and how communities could be identified within the network.

The analysis included:

- Network construction and visualisation.
- Girvan–Newman community detection.
- Greedy modularity optimisation.
- Louvain community detection.
- Comparison of community structures using modularity.
- Hierarchical clustering using single, complete and average linkage.

[View Assignment 2](owusu_NSBD_Assignment_2.ipynb)
